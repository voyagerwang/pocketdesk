# 耳机操作录制与映射

## 2026-10-08 确认的交互

先让用户操作耳机，确认收到什么信号，再指定动作。入口为耳机设置中的“录制新操作”。可直接录制，也可先选单击、双击、长按；不支持的预设不可选且给出原因。一次有效操作即可进入动作配置，不强制重复两次。单击须等待短暂的双击判断窗口，长按须松开后才完成确认。

主流程：选设备 → 开始录制 → 操作耳机 → 显示实际识别结果 → 选择动作 → 保存。检测期间不执行自定义动作；耳机原生媒体或输入法功能仍可能响应。音量信号只能确认增减，不声称能识别左右耳、双击或长按。识别失败保持录制/明确超时，可重试或切换预设；切预设自动重新准备检测。不同按键独立判断，避免把两次不同按键当作双击。

识别后才显示动作、快捷键或应用等必要字段。语音默认快捷键不常驻，放在按需展开的输入法设置中。范围显示应用名称。保存失败保留操作和配置，取消/关闭停止检测、快捷键录制与待执行试用。已有规则直接编辑，重新录制是可选操作；通用与应用专属规则明确区分。
