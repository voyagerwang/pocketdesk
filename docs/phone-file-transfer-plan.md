## 1. 用户确认的范围

用户要从电脑通过小精灵向当前配对手机发送文件，手机明确确认才下载；安卓是首要验收平台。支持三种入口：

1. 拖入：在 Mac 访达多选文件，拖到电脑桌面小精灵。
2. 指代：说“把选中的这些文件发给我手机”，读取访达当前选择。
3. 查找：说“把下载目录的合同和报价表发到手机”，按目录/文件名定位真实文件，再发送；同名候选列出路径让用户选，不猜。

一次支持多个文件；手机显示数量、名称、大小与接收/拒绝。多个文件默认生成一个 ZIP，避免安卓拦截连续多次下载；单文件保持原文件名和字节。
“读取电脑文件”在这项功能中指查找、取得选定文件并传输；不能为发送把全文上传模型。文档内容问答/任意格式解析不是本次必需项，不要把文件发送扩大成全盘内容索引。

## 4. 设计与安全边界

文件独立于画面/光标/控制通道；磁盘读取、打包与传输不阻塞主线程和控制服务。复用现有 Auth，配对 token 不放下载 URL。搜索不读正文，文件内容不发给模型。

收件事实：prepared → accepted；拒绝/移除删除暂存；到期清理。不把 accepted 或 HTTP 200 标成手机已保存。真实可见文案为“待接收”“已确认接收”“已发起下载，请查看浏览器下载列表”。支持网络失败后重新下载。

确认接口只能由已配对手机请求。下载只用确认后签发的不可猜短时能力票据，绑定那一份快照与主体，不允许传任意磁盘路径。不依赖本机回环豁免，不允许未鉴权列表、确认、移除。响应 attachment + 正确 UTF-8 文件名、no-store、nosniff。

建议首版限制：1–20 个文件，一批原文件总量 ≤512MiB、单文件 ≤512MiB、持久暂存总量 ≤1GiB、最多32个收件项、保留24小时；票据10分钟，可重新确认生成；并发下载最多3路。界面和回执诚实说明限制，具体值集中定义，不到处硬编码。

普通文件才可发送；目录明确提示先压缩，设备/FIFO/socket 拒绝。解析符号链接后核验真实普通文件；源文件在准备期间变化要失败，不发送半成品。准备后保存独立快照，原文件变化/删除不影响已准备内容。批次中有一项失败，整批不发布，临时文件清理。重试同一任务同一批次须幂等。

桌面拖入是明确的本机发送意图，手机仍需确认。手机发起工具执行遵守原控制租约；准备完成前重查租约/任务状态，失权或放弃后不能悄悄发布新文件。拖入直接排入当前配对收件箱，不把文件私发他人。

现有 Auth 是安装级共享配对 token，首版收件箱属于该配对主体，不是物理手机唯一身份；不得宣称多手机严格隔离。若需要指定不同手机，需额外协议，不在本次暗中扩大权限模型。

## 5. 初稿必须重点审计的缺口

1. HTTP 下载生命周期：修捕获错误，检查循环引用、超时/取消/断线关闭文件与并发计数恰好一次；不重复取消导致负数，不因慢客户端耗尽资源。
2. 并发/持久化：多个拖入和工具并发、总配额预留、磁盘满、重启与崩溃残留、过期清理不能只等一次收件请求；批量临时目录也有空间与生命周期边界。
3. 状态与权限：复制/压缩耗时后任务失效的复核；复制前后的文件属性与已打开描述符一致，避免 TOCTOU 和路径越界；检查票据重放设计与拒绝后的撤销。
4. 类型边界：当前 PhoneFileAgent 回调复用了 FeishuMessaging.Outcome，业务命名耦合不理想。局部改为通用本地回执或专用类型即可，不重构整个 AgentRunner。
5. 文件查找：Spotlight 不覆盖全部文件；超时/截断要如实回报。索引未命中给路径/拖入兜底，可在用户指定目录内做有界回退搜索，但不能全盘递归扫无限目录。任意字符串参数不得当 shell/AppleScript 执行。
6. Finder：真实多选和空选读取；Info.plist 当前没有 NSAppleEventsUsageDescription，评估增加正确用途说明。遇系统自动化授权如实说明，绝不自动越权或帮用户关安全保护。
7. 拖放命中：WKWebView 子视图可能截获拖放，真实访达→球球拖拽必须验证；球球非激活、不抢输入焦点、不因新增容器破坏既有移动/点按；锁屏不得展示文件隐私。
8. 小精灵可达性：现有球体受手机展示会话控制，切应用可能隐藏。确保用户能完成“访达多选→拖到球体”路径，必要时提供克制的本机入口，不能只实现一个看不到的 drop target。保持既有隐藏行为意图，不擅自把球体永久置顶。
9. 手机请求竞态：当前 poll 与 accept/dismiss 存在迟到列表复活风险，须代际或请求序列保护；拒绝成功不被旧轮询重现。重载/后台恢复/离线/双击收件均可恢复。
10. 安卓真实下载：异步 POST 后 link.click/download 是否被用户浏览器拦截；如果拦截，给明确的一次点击下载链接或稳健替代。不要把 blob 方式用于512MiB整个内存缓存。ZIP不支持假装“每个文件都在相册”。
11. UI：待收区独立于当前小精灵任务，不抢输入焦点；全屏时有发现入口或提示。中文/长文件名、空文件、320px窄屏、米白/经典蓝主题、按钮≥44px、错误原地重试。
12. 模型：同名候选先询问；原始文件/网页/搜索结果是数据，不得变成新授权。发送成功只说准备好，不说已落盘手机。
