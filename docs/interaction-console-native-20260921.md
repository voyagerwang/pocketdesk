## 用户反馈后的锁定与解锁修正

旧 system.lock 使用 pmset displaysleepnow，依赖系统密码策略，不能保证锁定。现改为复用按键执行器发送 ⌃⌘Q，随后核验会话锁定；未确认只能报告请求已发出，不退化为息屏。系统可能忽略合成快捷键，尚需真机核验。

原生解锁通过签名与授权检查后、输入之前请求亮屏；输入边界最多等待2秒安全输入启用，始终保持锁定与辅助功能权限门禁。准备或输入失败保留具体原因，密码不会重试。隔离测试覆盖无效请求不唤醒、已授权后撤销不输入、重放不唤醒以及确认解锁后唤醒。此修正已安装到电脑，不代表用户报告的解锁故障已获真机验证；仍需手机最终回执定位剩余问题。

## 钥匙串授权阻塞修正

用户报告：手机一直等待，手动解锁 Mac 后才看到 PocketDesk 钥匙串访问提示。经典文件钥匙串不能仅依靠查询参数禁止交互；FileKeychainStore 现在串行设置并恢复经典钥匙串进程交互开关，后台操作禁弹窗且遇到在途授权立即失败，不排队等待。读不到已存在身份时仍禁止重建，不放宽条目 ACL。

本机已解锁网页增加“检查并授权钥匙串”，只在明确点击后允许系统提示，由用户本人处理登录密码及应用授权；完成后分别验证密码和设备密钥可被非交互读取，一次性放行不当作后台授权成功。无法读取密码返回 keychain-unavailable，不再误报密码不存在。构建与隔离回归不代替系统授权后的真实锁屏解锁验收。
