# App 布局与快捷键删除修复（2026-09-21）

Android 0.2.1/versionCode4：连接后移除原生顶栏，只保留网页标题和齿轮；空状态提示 GONE，不再占据顶部空间。App 连接设置迁入网页齿轮，原生仅响应当前同源主框架的用户导航。普通浏览器不显示该入口，页面加载失败仍保留恢复入口。首次连接标题与菜单垂直对齐并缩减顶部间距。
