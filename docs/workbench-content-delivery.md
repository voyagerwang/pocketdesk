# PocketDesk → 个人工作台内容创建

2026-09-28 已实现：四个独立工具创建待办、本地日程、知识库文档、随手记。模型工具按类型暴露字段，避免把待办计划日期传入日程。默认目的地是个人工作台；显式飞书请求保留原飞书能力。

- PocketDesk：`Sources/WorkbenchContent.swift` 复用本机工作台业务 API；`AgentRunner` 注入当前本地时间并注册工具；`TaskStore` 原子持久占用和保存回执，旧快照不能清除证据。
- Workbench：`server/src/routes/local-events.ts` 补充本地日程创建与按 ID 读取；`local:` 外部身份避开 ICS/CalDAV 同步清理。同一请求同内容返回原记录，内容冲突返回 409。
- 成功条件：创建返回真实 ID，再按 ID 读取，核对标题、正文及对应时间字段。结果未知不自动重试。多个条目可以在同一轮串行创建。

验证：

- 原有 AgentRunner 回归通过。
- `tests/workbench-content.test.swift`：四类型字段映射、读回、服务离线、租约失效、未知结果、重启及旧快照去重、并发占用、真实 Runner 路由替身回归通过。
- Workbench `server/verify-local-events.mts`：隔离库验证持久化、读回、重复请求、冲突、非法日期、全天日期与同步清理隔离通过；服务端 TypeScript 构建通过。
- 使用本机当前配置的真实模型，一次自然语言请求创建四类测试内容；四条均完成 API 真实写入和读回。知识库条目在页面使用的资料池 API 中可见。手机实机输入和显示未在本次验收中操作。

边界：固定连接本机 `127.0.0.1:8787`，工作台需已启动且当前连接无需访问令牌；不发送外部日历邀请，不自动抓取知识库链接全文。尚不支持指定项目、知识目录或周期日程。

部署验收：最终版本已重装到 `~/Applications/PocketDesk.app` 并启动；安装后二进制含四类专用工具，PocketDesk 与 Workbench 健康接口均返回 200。四类最终联调条目均已从活动内容中清理，按 ID 读取返回 404；前两轮失败联调中已创建的待办也已清理。
