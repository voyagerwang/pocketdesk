# Web/
> L2 | 父级: ../CLAUDE.md

成员清单

index.html: 面向手机的单页工作台，无模式切换也无模式按钮：应用 Dock + 触控板卡片（收起 96px 精简条）+ 输入区（输入框下方的历史发送面板：清空带二次确认、收起按钮；图片预览）+ 按需打开的画面查看器（**两种形态：默认的 PiP 小浮窗 + 整层全屏（点全屏按钮进入）**；PiP 浮窗无专门拖把、整块任意位置可拖 + 8 个 .screen-resize handle + 只留切屏键与全屏/刷新/关闭三个圆形图标按钮的浮层 + #screen-cursor 鼠标叠加层；**没有状态条**）；触碰触控板自动展开、点输入框自动收起。
console.html: 电脑端控制台（自包含样式与脚本）。五步引导：系统授权（一键跳转设置）、手机扫码连接（局域网 QR + 自动探测的 Tailscale 跨网 QR + 在线状态）、目标应用搜索/增删/排序/自定义图标 + 每个目标的设置展开区（默认打开输入框/触控板偏好、应用专属快捷键组、叠加全局组开关 showGlobal 默认开、内置常用快捷键下拉框 BUILTIN_PRESETS 一键添加刷新/粘贴/复制/撤销/回车/锁屏/关闭等）、快捷键管理（录制产出语义串 hotkey 如 "Cmd+Shift+Z"/"Return"：主键只认 event.code 物理键位、不回退 IME 可污染的 event.key，拦截 isComposing 与纯修饰键；录制器为作用域模型 recordCtx，全局与应用专属共用同一 keydown 监听，录完即存，反馈就地显示在触发按钮上；键位标签用 .keycap 样式、label 与键位展示重复时只显示一个；支持重录/排序/删除）、最近动作（每 3 秒轮询 /api/status 的 log 字段，时间/结论徽章/动作+前台/说明四列网格，结论分三色：绿=已生效、琥珀=已发出未确认、红=未执行或失败——手机端点了没反应时来这里查第一现场）；默认经典蓝主题，:root[data-theme="muji"] 按需切换米白克制风；头部"经典蓝/米白"分段开关 POST /api/theme 写 Mac 本机，手机页自动跟随。
screen.js: 复用 app.js 的 authHeaders；**入口是发送行的电脑按钮，点开即 PiP 浮窗，浮层有全屏按钮可切整层全屏（非模态 dialog，开着时主页触控板仍可操作）**；转屏交给手机自己转，画面比例由 object-fit 兜底；`?v=` 之外的版本说明见 style.css 条目。**panel.open 是唯一真值源**，不另设 viewState 跟它对齐；整层只有一张画面，控件全部浮在上面（.screen-hud 一排：切屏键 + 全屏/刷新/关闭三个 .hud-icon 圆形图标按钮），容器 pointer-events:none 才不挡住"点画面移光标"；**没有状态条**：取帧彻底失败（首帧没拿到 / 非瞬态错误）就 updating=false 停表 + 在画面区给一句话，点刷新才恢复自动——不再把逐帧状态挂到 UI 上刷；**HUD 常态淡出**（280px 小窗被按钮吃掉一半），**触屏没有 hover，靠 revealHud() 在 pointerdown 时加 .hud-visible 显形、2.6s 后自淡出**，进入浮窗与每次拖动都会亮一下（全屏态常显）；**显示器列表只有 #screen-display 一份数据源**（隐藏不展示），顶部切换键是它的视图，共用 select 的 change 流程，由 syncDisplays 同步；点画面移光标用 offset 坐标（元素局部系不受 transform 影响，转屏后照样准）并剔除 object-fit 留白，tap 命令自带 click 参数（点一下 = 移过去 + 左键单击，一条消息原子执行）；画面缩放交给手机双指捏合，不另设放大按钮；**授权联动**：撞到录屏权限墙时自动 POST /api/screen/permission 把电脑端系统弹窗喊出来（每次打开查看器限一次），随后每 3 秒轮询 /api/screen/displays 等用户在电脑上点「允许」，生效即自动接上画面，约 90 秒无果再退到手动指引；服务端 canRequest=false（本机已弹过窗，系统不再弹）时不空等，直接引到系统设置。**鼠标叠加层**：画面是 1fps 的 JPEG、光标是 30Hz 的坐标，两条通路各走各的（见 ../Sources/CLAUDE.md 的 CursorMonitor）；与点击映射**共用 contentRect() 一份几何**（各算一遍迟早算出两个不同的点）；暂停 / 光标不在当前屏 / 链路断 / 全屏态 四种情况一律不画——画了就是假实时（全屏只支持点按，不画移动光标）；链路活着（3 秒内有 cursor 帧）才请求 `cursor=0` 让画面不再烘焙鼠标，断了自动退回含鼠标截图（宁可旧，不能一个都没有）。**自动更新只有 scheduleNext() 一个调度入口**，回调里必须把 timer 置空——否则 clearTimeout 后句柄仍在、下一轮 `!timer` 恒假，更新跑完第二帧就悄悄停住且不报任何错；同理，先置 `updating=false` 再 scheduleNext 是句空话（scheduleNext 内部直接 return），要重试就别停表。
style.css: 手机页唯一样式来源（控制台样式内联在各自 HTML，令牌取值与本文件保持一致）。:root 里的设计令牌（颜色/间距/圆角/字号/动效）之外不允许出现硬编码色值。经典蓝玻璃主题为默认，:root[data-theme="muji"] 覆盖为米白克制风（米白 #f5f3ee 底 + 深炭字 + 赭红 #b74127 单一点缀、去发光去渐变去毛玻璃、方正小圆角）。两个主题共用同一套令牌名与选择器，切换零结构改动。主题是服务端状态，默认 classic（经典蓝）：电脑控制台头部"经典蓝/米白"分段开关 POST /api/theme 写 Mac 本机，手机页无按钮、经 /api/status 轮询跟随（≤5s），localStorage 只存上次已知值缓解刷新闪烁。**横屏**：`orientation: landscape` 且 `max-height: 560px` 时浮层再压薄一档（已无 .rotated 整层旋转——全屏态重建为不旋转的整层铺满（.screen-view.fullscreen：隐藏 resize、HUD 常显、不画鼠标叠加））。**PiP 浮窗** 走 `.screen-view.pip` 选择器：`position: fixed` + JS 写到 inline style 的 left/top/width/height，阴影 + 圆角，::backdrop 透明（让主页透出来）；**8 个 resize handle** 是浮窗边缘 18px 宽的带（nw/n/ne/e/se/s/sw/w），CSS 给出位置与 cursor（nwse-resize/nesw-resize/ns-resize/ew-resize）。**层叠顺序是硬约束，改前先想清楚**：`.screen-viewport`(1) < `.screen-resize`(3) < `.screen-hud`(5, 子元素再 relative z-index:1)，HUD 必须压过 handle，否则"刷新/关闭"点了变成拖窗口；pip 态 HUD 顶部让开 20px 才不与 18px 的 resize 带抢地。**`.screen-view` 基类绝不能写 `margin: auto`**——fixed 定位下 left/right/width 同时非 auto 时 margin:auto 会去平分剩余空间，算出负 margin 把整层推偏（"画面只剩一半"的历史根因，全屏态虽已删除，这条约束仍然有效）；`.hud-icon` 是 34px 圆形图标按钮 + 半透明底（**半透明底是硬要求**：白色图标遇到亮色画面会直接消失）；刷新按钮不再写"获取中"文字、只留图标。`.screen-cursor` 叠加层用 transform 定位（合成层不触发重排）、`pointer-events: none`（吃掉点击就会废掉"点画面移光标"）、热点对齐 SVG 箭头尖端（路径起点 1,1，svg 偏移 -1px）。
app.js: 手机页交互与本地 API 客户端。点击唤醒、发送命令（文字 + 可选图片：选图压缩到 2048px JPEG 预览，图片经 /api/image 预上传，发送时 SendCommand 携带文本与 usePendingImage 标记；服务端先输入文字，再经 Mac 剪贴板 Cmd+V 粘贴图片并统一提交）；手动激活目标后按其 openPanel 偏好自动切触控板/输入区（前台自动跟随不切，避免抢键盘）；触碰触控板自动进入 pad 模式（收键盘、面板长大），点输入框/发送自动退出并收起设置面板；每 5 秒轮询 /api/status：上报 /api/pair 心跳、让选中态边沿跟随 Mac 前台应用（滑动 Dock 4 秒内、手动激活 2.5 秒内抑制），伪目标态记住前台应用名 frontmostLabel，"发送到 X"一律显示识别到的真实应用名；触控板 Pointer Events 手势状态机（单指移动/点按/长按拖动、双指滚动/右键），增量经 rAF 合并后发往 ws:46388；历史面板展开时按钮高亮、相同内容去重、清空需二次确认（3.5s 自动还原）；快捷键按钮条随选中目标切换：有专属组时前排专属 + 后排全局（showGlobal=false 只显专属，默认叠加），无专属组用全局组（过滤默认 undo/copy/paste 示例），心跳边沿比对 targets 与 shortcuts 5 秒内跟随服务端，Enter/Return 等别名归一显示同一符号、名称与键位重复时只显示一个，点击 POST /api/shortcut-trigger 注入 Mac 前台；配对 token 管理（URL ?token= → localStorage → 写请求 Authorization 头与 WS 首帧 auth）、主题跟随（applyTheme 在 boot 与心跳里应用 /api/status 下发的 theme）。**同一条 ws:46388 也收下行**（此前是纯上行）：ws.onmessage 分发 auth_ok / cursor / error / closed，经 `window.pocketdeskOnWSMessage` 供 screen.js 订阅；`wsReady` 只说明 socket 打开、**不等于鉴权通过**，要等服务端 auth_ok 才是 `wsAuthorized`（回环豁免也回执，所以前端只有一条判定路径）。

<conventions>
图标分两类，不混用：目标应用一律用系统真实图标（服务端 /api/icon，取不到时露出首字兜底，控制台支持上传自定义图标覆盖）；界面控件一律用内联 24×24 线条符号，stroke-width 固定 1.75，颜色走 currentColor。
不使用 emoji、不使用第三方图标 CDN（页面要能离线跑）。
改了 style.css / app.js / screen.js 之后**必须同步 bump index.html 里的 `?v=` 版本号**（三个资源同一版本号），否则手机浏览器吃缓存，改完看不到效果——这类"改了但没生效"最难自查。
</conventions>
